## 0. 一句话定位
把吴晓锋老师的 **ANN→SNN 转换方法论**（FTBC / TPP / 并行转换）推广到**图神经网络**，提出首个"图感知的邻域时序校准"，在超低时间步（T≤8）逼近全精度 GNN 并保持 SNN 的节能 / 事件驱动优势。这是"吴老师的方法论"与"xhf 的图 SNN 应用"最自然的结合点，作为**首篇 B 会、冲 A 会**的方向。

## 1. 研究背景与动机

### 1.1 SNN 与 ANN→SNN 转换（吴老师的方法基座）
- **为什么 SNN**：脉冲神经网络以离散"脉冲"传递信息，事件驱动、天然稀疏，能耗可比稠密 ANN 低 1–3 个数量级，特别适合边缘 / 可穿戴场景——这正是吴老师 FDCT-ITP 项目《面向高精度低能耗的类脑脉冲神经网络训练与转换研究》(0078/2025/ITP2) 的核心关切。
- **训练难是瓶颈**：SNN 的脉冲发放不可微，直接训练依赖时空反向传播（STBP）或替代梯度，成本高、调参难、时间步开销大。
- **ANN→SNN 转换是主流轻量路线**：把预训练好的 ANN 转成 SNN，用脉冲**发放率**逼近 ANN 的激活值，免去 SNN 的直接训练。吴老师在此方向的关键贡献：
  - **FTBC**（*Forward Temporal Bias Correction for Optimizing ANN-SNN Conversion*, **ECCV 2024**, arXiv:2403.18388）：前向时序偏置校正，理论上可使"每步转换误差趋于 0"，在 CIFAR-10/100、ImageNet 上显著提升转换精度，代码已开源。
  - **TPP / Temporal Misalignment**（*Temporal Misalignment in ANN-SNN Conversion and its Mitigation via Probabilistic Spiking Neurons*，吴为主贡献）：提出"时序错位"概念与**概率脉冲神经元（Two-Phase Probabilistic, TPP）**，让 SNN 在**超低延迟**下匹配 ANN 精度。
  - **并行转换**（*Faster and Stronger: When ANN-SNN Conversion Meets Parallel Spiking Calculation*, **ICML 2025**）：首次把并行脉冲计算与转换结合，超低延迟。
- **关键局限（本文的出发点）**：上述转换法**只在 CNN / Transformer 图像分类与简单序列上验证**，从未覆盖**图神经网络（GNN）**。

### 1.2 图 SNN 的应用（xhf 的应用基座）
- xhf 已有扎实的图 SNN 应用积累：**P-SGCN**（脉冲图卷积 + 城市洪涝风险，一作 *Sustainability* 2025）、**SNN×图卷积洪涝**（二作 primary contributor，*iScience* 2024）。
- 现有图 SNN 几乎都是**直接训练**（替代梯度），存在训练难、延迟高、能耗优势未必兑现的问题。
- 图的消息传递在 SNN 中会发生本质变化：邻居脉冲在**不同时间步异步到达**后才聚合——这正是本文要研究的"图上转换失效"的来源。

## 2. 核心问题、缺口与洞见

| 项 | 内容 |
|----|------|
| **Problem（问题）** | GNN 算力 / 能耗高、难以边缘部署；把 SNN 用到图上，现有做法是直接训练，训练难、延迟高。 |
| **Gap（缺口）** | 视觉 / 序列上的 ANN→SNN 转换已成熟（FTBC / 并行转换），但 **GNN 的转换无人系统研究**；现存的脉冲 GNN 不是"转换"而来，而是直训。 |
| **Insight（洞见 / 创新核心）** | 图聚合的异步脉冲传播 = **邻域时序错位（neighborhood temporal misalignment）**，是图上转换失效的主因；可把 FTBC 的"通道级时序偏置"推广为"邻域到达分布校准"，并用 TPP 概率神经元补偿超低时间步下的信息密度。 |
| **Evidence chain（证据链）** | 理论（错位误差上界）→ 校准方法 → 在 Cora / CiteSeer / PubMed + 自有洪涝图上，对比全精度 GNN、直训脉冲 GNN、FTBC / 并行转换适配版；指标 = 精度 / 时间步 / 能效（理论 spike 数）。 |

> 注："temporal misalignment（时序错位）"是吴老师在 ANN-SNN 转换中提出的通用概念；本文将其**具体化为图上的"邻域时序错位"**并给出图特有的校准机制——这是方法的增量创新点。

## 3. 方法（详细）

### 3.1 转换管线（Pipeline）
1. 训练 / 加载预训练 **ANN-GNN**（GCN / GAT / GraphSAGE）。
2. 将其激活函数替换为脉冲神经元（Integrate-and-Fire 或 TPP 概率神经元）。
3. 用"邻域时序校准"修正聚合时的错位。
4. 输出低时间步、低能耗的 **SNN-GNN**。

### 3.2 邻域时序错位建模（核心机制）
- 在 ANN-GNN 中，聚合是同步的：`h_i = Σ_j w_ij x_j`。
- 在 SNN-GNN 中，邻居 `j` 的脉冲在**不同时间步** `t + δ_j` 才到达 `i`，固定时间步 `t` 的快照因此不一致——这就是邻域时序错位。
- 形式化错位误差上界（推广 FTBC 在图像上的误差分析）：把"通道偏置"替换为"邻域到达分布"的校准项，证明在合适的校准下，逐时间步的聚合误差可被压制。

### 3.3 图感知时序校准（推广 FTBC）
- FTBC 在图像上按通道做前向时序偏置；本文按**邻居到达分布**（度 / 距离加权膜电位）做聚合校准。
- 提供轻量、无需重训练的校准算法（类似 FTBC 的前向启发式），把计算开销留在前向。

### 3.4 概率脉冲聚合（超低 T）
- 在时间步 T≤8 时，确定性 IF 神经元会丢失信息；引入 **TPP 概率脉冲神经元**，在超低 T 下保持跨邻域的信息密度（吴在视觉上已证有效，本文迁移到图）。

## 4. 创新的证据（为什么这件事是新的）

### 4.1 创新点清单
1. **首个面向 GNN 的 ANN→SNN 转换框架**——区别于所有"直训脉冲 GNN"，训练成本更低、延迟可控。
2. **提出"邻域时序错位"这一图特有的新机制**，并给出误差上界与分析（不是简单套用视觉转换）。
3. **图感知时序校准（推广 FTBC）+ 概率脉冲聚合**，构成可复现、可证伪的方法。

### 4.2 新颖性证据（差异化分析）
- **vs. 直训脉冲 GNN**：现有脉冲 GNN（如 SpikeGraph 一类的替代梯度直训工作）需要从零训练 SNN，而本文是"转换 + 校准"，直接继承预训练 ANN 的能力，训练 / 延迟优势明显。→ **角度不同，不构成重复。**
- **vs. 视觉 / 序列转换（FTBC / 并行转换）**：那些方法处理**规则网格 / 序列**，本文处理**不规则图 + 异步聚合**，机制不同（错位来源从"通道时序"变为"邻域到达时延"）。→ **模态与方法扩展，非移植。**
- **文献检索证据**：截至本方案撰写，未发现"GNN 的 ANN→SNN 转换"的高相似工作（直训脉冲 GNN 与视觉转换分属不同族）。**待精确检索核对直训脉冲 GNN 近年工作以最终确认 G4 不重复**（这是锁方向后的必做项）。
- **风险边界**：若检索发现已有"GNN 转换"高相似工作，则降级为 `pivot-with-rescue-route`，转向 D3（EEG）或 D2（动态图），不在空洞 novelty 上硬撑。

### 4.3 为什么评审会认可
- 图学习 × 类脑计算是交叉热点；SNN 在图像上已证节能，但"图上的转换"是**明确空白**。
- 故事不止"换个模态跑 benchmark"：提出了**邻域时序错位**这一可证伪新机制，有理论（误差上界）与消融支撑。

### 5.3 硬件可行性（G5 ✅）
- 本机：**RTX 3060 12GB + CUDA 13.1 + torch 2.11**，12 核 CPU，568GB 空闲。
- 小图（Cora / CiteSeer）分钟级，PubMed 小时级；预算 runtime ≤ 24h、mem ≤ 12GB、**种子 ≥ 5**。
- **默认本地执行，不上云**（除非扩展到 ImageNet 级或超大图，届时需 xhf 显式授权）。

- TPP（吴）已证：概率神经元在超低 T 保持精度（视觉）。
- **Kugele et al., 2020, *Front. Neurosci***（序列转换需 delay-matching，数据集 N-MNIST / CIFAR10-DVS / DvsGesture）：**独立佐证"非图像模态的时序错位是真问题"**——支持本文"图也存在错位、需专门校准"的机制假设。

## 6. 实验设计（展开）

- **数据集**：Cora、CiteSeer、PubMed（节点分类）；自有洪涝图（真实域）。
- **Baselines**：
  - 全精度 ANN-GNN（GCN / GAT / SAGE）——上限，`must-rerun`。
  - 直训脉冲 GNN（替代梯度）——直接竞品，`adaptation-attempt`。
  - FTBC / 并行转换**适配到图**——转换基线，`adaptation-attempt`。
  - 朴素转换（无校准）——内部对照，`internal-matched`。
- **变体**：有 / 无邻域校准；有 / 无概率脉冲聚合；T ∈ {1, 2, 4, 8, 16}。
- **消融（可证伪）**：
  - **F1（校准必要性）**：去掉邻域校准 → 若低 T 精度不显著下降，则"邻域错位"假设弱。
  - **F2（概率神经元必要性）**：换确定性 IF → 若超低 T 不塌，则 TPP 贡献弱。
  - **F3（分布估计）**：均匀到达假设 vs 估计分布 → 若相当，则分布建模冗余。
- **指标**：主 = 节点分类准确率；次 = 时间步 T、理论 spike 数（能效）、推理延迟（若 neuromorphic 模拟）。
- **统计**：5 随机种子均值 ± std，配对 t 检验 vs 基线；Cora sanity check 用独立种子，不与主结果重叠。
- **停止条件**：低 T（≤8）精度落后 ANN-GNN > 5% 且 F1 / F2 无救 → 退回"直训脉冲 GNN + 转换对比"重定位。

## 7. 预期结果与判定

| 档位 | 标准 |
|------|------|
| **minimum（可接受）** | T≤16 时转换 GNN 精度 ≥ ANN-GNN −3%，且优于朴素转换 ≥ 2%。 |
| **expected_strong（强）** | T≤8 时精度 ≥ ANN-GNN −1.5%，且理论 spike 数显著低于直训脉冲 GNN。 |
| **failure（失败信号）** | T≤8 精度落后 > 5% 且校准消融无增益 → 机制证伪，重定位。 |

>  Integrity rule：期望结果指导优化，不指导报告。若认真迭代后仍达不到强结果，报告最诚实的结果并解释差距，绝不复现 / 造假。
