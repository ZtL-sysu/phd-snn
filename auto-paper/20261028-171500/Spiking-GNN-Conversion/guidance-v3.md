# Guidance v3 — 定稿论文的契约 + 创新性证据

> 版本关系：v1（实验前，方法假设后被否）→ v2（按实测卖点重写）→ v3（定稿版，补外部基线后收窄主张，并附创新性证据）。

## 1. 一句话卖点

**把「训好的 GNN 换成脉冲网络」写成一个可分析的对象**，给出精确误差恒等式、闭式偏置
`β* = θ/(2T)`、膜电位解码与 margin 定理；卖点是**部署灵活性（训一次、任意 T、设备上无反向）
与低时延**，不是能耗，也不声称精度 SOTA。

## 2. 创新性证据（"确保没人做过"的可核查边界）

| 主张 | 检索证据 | 结论边界 |
|---|---|---|
| 图上没有 ANN→SNN 转换的**误差分析** | arXiv 全库检索 `spiking AND graph neural network` 共 33 条（2020–2026），逐条看标题与摘要：全部是**直接训练**的脉冲 GNN（SpikingGCN/SiGNN/DGSNN/SpikeGraphormer/几何感知/Riemannian/Loihi 部署/SGNNBench 评测），没有一条做转换误差分析 | 可以说是 **formulation-level 首次**；不能说是"首个图 SNN" |
| 邻域时序错位是**新现象** | ICML'25（Bojković, Wu, Gu, arXiv:2502.14487）的 temporal misalignment 指**层间**随机置换；本文指**同一聚合内部的邻居相位差**。两者对随机性的结论相反（TPP 只在小 T 有利，我们在 T≥2 观测到相反） | 必须显式区分，不能声称是同一现象；§2 已单列一段 |
| 闭式 `β* = θ/(2T)` | 机制来自 FTBC（ECCV'24），其偏置为校准/前向时间偏置；本文给出 `ρ_n ≠ 1` 时的闭式值，并证明系统项按 `ρ_n` 加权、相对误差 `ρ`-不变 | **机制不算新**，值、`ρ` 加权与 `ρ`-不变算新；§2「继承与未继承」已写明 |
| 膜电位解码 | 本文证明 `mem = c₁θ + u = Σ_t inst_t` 恒等，去掉**计数**解码的 1/T 网格与截断天花板 | 不说"前人都用计数"，只说"我们量化了计数解码的代价"（−3.68/−6.24/−0.01 pp） |
| margin 定理 | 给出 `T = O(‖a_n‖₂‖DW‖₂/Δ_n)`，30/30 不被反例推翻，并量化保守 3.2–6.7× | 是充分条件、非配方（`Δ_n` 需训练后算），如实写 |

**检索方法与可复核性**：arXiv API 查询语句与返回的 33 条标题记录在案（`protocols/`、会话记录）；
`SGNNBench`（arXiv:2509.21342, 2025）是同期最大规模评测，其中不含任何转换方法——这是"空白"的**正向**证据。
**证据的界限**：这只覆盖 arXiv + 我检索到的公开文献，不能排除未公开或非英文工作；论文措辞因此用
"we are not aware of / no published analysis"，不用"the first ever"。
