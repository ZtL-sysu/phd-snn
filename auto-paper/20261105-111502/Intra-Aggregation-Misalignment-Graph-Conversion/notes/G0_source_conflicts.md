# G0 — conflicts between the task book and primary sources

Policy: truthfulness is a hard gate (task book §0 iron rule 3, and f-research-v1 non-negotiable
rules). When the task book's numbers or names disagree with a verified primary source, the primary
source governs, the discrepancy is recorded here, and **nothing is silently overwritten** in the
scientific claims. Contract items C10, C11, C12.
