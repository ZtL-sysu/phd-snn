【刺激，明确标注 SYNTHETIC】T=8 帧、32×32、n=400、二分类 direction：
半径 3–5 的圆点，起始 x 随机 8–24，逐帧 speed=2 向左或向右，标签=方向。
另做 flash control（闪烁检测）作为负对照。固定 70/30 stratified split，
主口径 seeds=[1,2,3,4,5] 与预注册扩展 seeds=[1..11]（后者只增独立初始化 seed，
刺激与 split 完全相同）。
真实域标签构造、输入编码阶梯、三态判定规则、暴露/未暴露 holdout 划分、
阴性对照校准判据、检验族与 BH family **全部训练前**写进 `config_preregistered.json`
并 SHA-256 哈希锁定；类别需平衡；`matched_n` 子采样保证各档 n 一致。
SYNTHETIC 只是受控诊断域，**所有迁移结论只在真实域 ceiling 达标时才可下**。

【条件矩阵 · 每个条件两种子口径，同一批刺激与同一 split，等参数量】
A. 历史可比锚点（SYNTHETIC，5 条件 × 5 seeds）：stateless / lif_homeostasis /
   lif_combo / degree_null_lif / A=0，冻结特征 + train-only ridge（与 18156..18448 可比）。
B. 【核心】梯度路径 2×2：`{frozen+ridge, surrogate_gradient_e2e} × {stateless, LIF}`
   + `stateless_trained_identically` + 三变体（learnable_decay / learnable_gain_only /
   straight_through_rate），全部等参数量、等 SynOps、train-only、训练前冻结；
   每条件 5 / 11 seeds，落盘训练曲线、最终 accuracy、delta、bootstrap 95% CI、
   exact p、BH q、spike rate、feature std、SynOps 代理、peak GPU MiB、耗时。
C. 【必修 ①】阴性对照校准诊断：置换构造审计、零效应蒙特卡洛 >=200 次的
   三检验族经验 I 类错误率、逐环节张量指纹重合度；输出
   `negative_controls_calibrated_nonsignificant` 与 `uncalibrated_contrasts` 清单。
D. 【必修 ②】DAVIS 输入编码一因子修复阶梯（5 个单因子 × on/off），每档
   ceiling + CI + oracle−current gap + Fisher 比 + MI + 类别平衡 + 样本量；
   全部档落盘、全部报告；只有 ceiling >= 0.70 才升级 DOMAIN_USABLE。
E. 【必修 ③】SINTEL delta 恒 0 三态判定：逐环节逐跳逐帧张量指纹差异计数与哈希、
   单位级反事实注入、强制分支判别探针；输出 `sintel_zero_delta_state`。
F. 【主读出升级】训练后动力学下的 SINTEL real-domain `delta(LIF − stateless)`：
   5 / 11 seeds、bootstrap 95% CI、三检验族 p、BH q，并按 C1 guidance §Expected
   Results 给 `minimum` / `expected_strong` / `failure` 判定。
G. 三态 `decidability_state` 次级门（每个真实域一个，只有 DOMAIN_USABLE 允许 real delta）
   + 跨实现一致性固定协变量审计（7 单因子 + 两端点，仅保留可比性，不重跑全表）。
H. 测试集暴露台账：exposed / unexposed 两套数值分别全部报告；
   最终选择只在未暴露 holdout 上评估一次。
I. 一因子消融（从 lif_combo 分别移除自适应阈值 / 不应期 / E/I 符号，各 5 seeds）
   与阴性对照（打乱帧序、flash、冻结 gain、标签置换、保度零模型、identity 图）；
   冻结探针臂等效性 / 非劣效界（CI 是否排除 +0.15）。
每条件记录 spike rate、feature std、非常数维、逐跳 probe_acc、Fisher 比、peak GPU MiB、耗时。
所有统计：2000 次 bootstrap 95% CI、exact paired sign-flip p、BH-FDR q=0.05；
统一报告 5 paired seeds 下最小双侧 p=0.0625 的效力限制，以及 >=11 seeds 下的新下限。
**不许用 held-out test 表现去选择训练配置、输入编码档、seed 数、检验族或任何超参。**

【训练前强制自检 · 任一失败先完成诊断再落盘，不得零信息终止】
1. `kc_reachable_count`：eye→KC exact-hop 可达数（hop 1..8 全报）；按冻结回退规则取 K。
2. `synthetic_ceiling >= 0.90`：8 帧展平 ridge 的 5-seed 天花板均值。
3. `real_domain_ceiling`：沿用 18448 已实测的冻结口径（DAVIS 0.613333 /
   SINTEL 0.700000）并复测；门槛恒为 0.70；任一域 < 0.70 标 unavailable；
   两域现行口径都 < 0.70 则 `migration_verdict` 明确写
   `NO_TRANSFER_CLAIM_BOTH_REAL_DOMAINS_UNAVAILABLE`，**不作迁移主张**。
4. `gradient_path_actually_distinct`：训练前用单位级反事实注入确认
   `surrogate_gradient_e2e` 分支确实接收梯度、`frozen+ridge` 分支不接收；
   若无法区分则标 `IMPLEMENTATION_IDENTICAL_BRANCH` 并落盘全部诊断再结论。
5. `negative_control_calibration`：C 的判据在看到任何主 contrast 结果**之前**冻结并执行，
   未通过则本 run 全部 contrast 标 `uncalibrated`（不是终止、不是删除）。
6. `data_integrity`：每个下载文件实测字节数与 SHA-256 落盘；不一致标 unavailable。
