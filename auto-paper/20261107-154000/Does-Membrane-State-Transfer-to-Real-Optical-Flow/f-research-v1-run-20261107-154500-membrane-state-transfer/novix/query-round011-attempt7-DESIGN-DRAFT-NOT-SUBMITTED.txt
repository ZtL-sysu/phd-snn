【本轮假设 · 机制级不同于 attempt #6】
================================================================================
attempt #6（`18489`）的假设是「膜状态递推从未接收梯度，梯度路径才是
未被检验的自变量」，其三项必修分别针对：阴性对照校准（统计检验层）、
DAVIS 输入编码（表示层）、SINTEL delta≡0 的两条件实现分支（代码路径层）。
**三者共同默认了一件事：读出与决策规则本身是「可辨识的」**——即若存在
真实效应，现用的 train-only ridge + argmax 流水线能够把它表达成一个非零 delta。

本轮假设（新，机制级不同；是假设不是结论）：
前 6 次实验反复出现的「两条件 accuracy 完全相同 / paired differences 全 0 /
delta 恒 0」与「阴性对照却显著非 0」这一**组合**，可能不是膜状态的性质，
而是**测量装置不可辨识（measurement-apparatus non-identifiability）**：
  ① 决策规则退化：两条件在真实域上塌成同一个常数/多数类预测器
     （0.466667 与类别边际、混淆矩阵、logit margin 的结构未被报告），
     此时 `delta≡0` 是**测量产物**，既不是负结果也不是正结果，
     而是**不可解释（uninformative）**；
  ② 缺少**阳性对照灵敏度**：历轮只有阴性对照（标签置换 / 零效应注入 /
     打乱帧序 / flash / 冻结 gain），**从未在真实域特征流水线上注入一个
     已知强度的信号并检验读出能否单调恢复它**。没有灵敏度传递函数，
     就无法排除「即使真实存在 +0.25 的膜状态增益，本装置也测不出来」。
  ③ 18448 的阴性对照显著非 0（`−0.115909`, p=0.0009765625）与主对比
     恰好全 0 并存，暗示**条件身份 / 标签边际 / 归一化统计量的作用方式**
     可能在不同对照间不一致；attempt #6 的必修①只查置换构造与经验 I 类错误率，
     **不查决策规则本身是否退化**。

可证伪推论（全部训练前冻结、可落盘判定）：
  (i) 若装置可辨识：混淆矩阵非常数、`predicted_class_marginal` 非退化、
      logit margin 分布有非零方差，且**已知信号注入阶梯**的恢复斜率 > 0
      且 bootstrap CI 下界 > 0；
  (ii) 若装置不可辨识：两条件塌成常数/多数类预测器，或注入已知 +0.25 强信号
      后读出恢复量仍 ≈ 0 → 则**18448/18390/18489 一切 `delta≈0` 的判定
      必须改标 `UNINFORMATIVE_MEASUREMENT`**，不得作为「膜状态无增益」的
      科学结论，也不得作为「有增益」的结论；
  (iii) 该重分类**不会把任何失败改写成成功**：`c1_guidance` 仍是 failure、
      `transfer_claim_made` 仍为 false、文章仍不合格、仍继续死磕同一 C1。

**与 attempt #6 的关系**：不是否定梯度路径假设（`18489` 结果未出），
而是在其上**新增一个更前置的硬门**——若 `18489` 的 e2e delta 仍 ≈0，
必须先证明「装置能测出已知效应」，那个 0 才有资格被解释。
`expected_strong(+0.25)`、`minimum(+0.15)`、真实域 ceiling 0.70 **均不下调**。
