【§2 本轮假设（H11，机制级不同于 H10 / H9 / #6 / #7 / #8；是假设不是结论）】
================================================================================

命名：**标签—输入信息预算可辨识性假设（information-budget identifiability）**。

观测起点（全部来自 18696 已落盘实测，不推断）：
· `gt_oracle_upper_bound=1.0` ⇒ 官方 GT 光流 `.flo` 本身对任务标签**完全可分**；
· 但当前 ceiling 仅 `0.424242` / `0.400000` ⇒ 约 0.58–0.60 的可判定性
  在「GT 光流 → 网络可读输入」这条链上丢失；
· `INPUT_SIGNAL_PATH_MEASURABLE` + `localized_unit=syn` + `H_slope` 逐环节全负
  ⇒ 链路是通的、能量/增益在衰减，但**「衰减的是任务相关信息还是纯幅值」从未
  被分开测量**——历轮所有估计量（H_slope、能量比、恢复斜率、forced probe）
  都是**幅值/增益类**，没有一个直接测「标签信息量」。

  **H11（可证伪）**：ceiling < 0.70 的主因不是突触前能量稀释（H10），
  也不是标签噪声（H9），而是**光流→离散标签的量化映射与 4×4 复眼空间下采样
  联合造成的可判定信息塌缩**；该信息损失发生在 `drive→syn` **之前**，
  因此对 LIF 与 stateless 同样生效，这解释了历轮「两臂 delta 恒 ≈0 /
  逐环节全负 / 校准失败」的共存现象。

  可测后果（两支都必须报告，禁止选择性报告）：
  (a) 若训练前冻结、SHA-256 哈希锁定的**条件互信息预算阶梯**显示
      `I(4x4_sampled; Y) << I(raw_32x32_luminance; Y)` 且
      `I(readout_LIF; Y) ≈ I(readout_stateless; Y) ≈ I(4x4_sampled; Y)`，
      则瓶颈被定位到**输入空间下采样 / 标签量化**，落
      `LABEL_QUANTIZATION_OR_SAMPLING_BOTTLENECK`（诊断型负结果），
      下一轮转向「冻结标签离散化族 × 复眼池化核」的一因子阶梯；
      此时即使 H10 的 yoked 能量档把能量比抬到 ≈1，也不得据此作迁移主张。
  (b) 若 `I(4x4_sampled; Y) ≈ I(raw; Y)` 而 `I(readout; Y)` 在 LIF 分支
      显著低于 stateless（超出置换零基线 CI），则 H11 被否证，
      信息损失发生在读出/膜状态侧，落 `READOUT_INFORMATION_LOSS`，
      下一轮转向 `syn→v` 电流—脉冲转换代数的信息论版本（round-016 交接
      的 `SYNAPTIC_ENERGY_NOT_CARRIER` 分支承接）。
  (c) 若所有估计量都落在置换零基线内（不可辨识），落
      `UNINFORMATIVE_MEASUREMENT`（第四态），**不作机制结论**，
      如实记录并按 correction loop 继续同一 C1。

  配套两个**历轮从未做过的必跑门**：
  · **无参数互信息估计器的校准门**：训练前冻结离散化 bin 数网格、
    Miller–Madow 偏差校正、≥200 次标签置换零基线（给出经验 I 类错误率与
    Wilson 95% CI），并在已知 +0.25 信号注入阳性对照上验证估计器灵敏度
    （18533 只做过 accuracy 版：恢复 `0.067901`/`0.0625`，斜率 `0.284383`/
    `0.155642`，属亚单位灵敏度；本轮做**信息量版**，且必须先过校准才允许
    解释任何 I 值）。任一格未通过 → 全部 `I` 标 `uncalibrated`。
  · **`A=0` 上界的信息论重验门**：历轮只把 `A=0` 当 accuracy 上界
    （`0.458` / `0.515152`），从未测过 `I(A=0; Y)`。本轮把
    `I(A=0; Y)` 与 `I(degree_null; Y)` 一起纳入阶梯，
    直接检验「保度零模型从未输给真实接线」在信息量层面是否同样成立；
    **禁止**据此宣称生物接线优势。

  反向护栏：H11 **不得**被用来下调门槛或改写结论；只要 ceiling 仍 < 0.70、
  校准仍失败或 unexposed 符号翻转，`c1_guidance` 仍按实测判 failure、

以下均为**机制 / 协议 / 估计量 / 实现层**变化，不是只调超参、不是改标题、
不是原样重提、不是重跑同一网格凑显著：

 1.【新增·第一主门，历轮从未做过】训练前冻结并 SHA-256 哈希锁定的
   **`information_budget_ladder`**：沿
   `raw_32x32_luminance → 4x4_compound_eye_sampled → retinal_drive →
   syn → v → spike → KC → logit` 八级，逐级别落盘 `I(X_level; Y)`

   H10 是干预，本轮是测量；两者可在同一 run 内互不污染）。

   `drive_to_syn_energy_ratio`、`H_slope_recovery`、forced-probe 精度）。
