**H12 = 「判定装置一致性」假设**：连续多轮 `REJECT_FAILURE` 中反复出现的
`delta≈0`、阴性对照校准失败、exposed/unexposed 符号翻转、

**至少部分不是生物物理机制结论，而是判定/聚合管线自身的四类实现缺陷
（BH 家族范围漂移、恢复旧 payload 与 manifest 源码不同版、崩溃恢复缺
必填字段、finalize 枚举不全）在测量层面造成的伪影**。

与前面各假设的**正交性**：
  · H10（已提交 18885）改的是 **突触前 `drive→syn` 界面归一化算子**
    （yoked 能量匹配），作用在「信号如何进入网络」。
  · H11（round-017 预案）测的是 **沿前向链的条件互信息阶梯**，
    作用在「标签信息在哪一跳丢失」，是**测量**但不干预。
  · H12 两者都不动：它把**判定装置本身**（统计家族定义、恢复一致性、
    manifest↔payload 绑定、finalize 枚举完备性）作为唯一自变量，
    在网络与数据完全不变的条件下，用**已哈希核验归档的历史原始数值**
    做**离线重判定**（re-adjudication），检验「换用一致的判定装置后，
    历史 verdict 是否改变」。

**双向可证伪落点**（预先写死、不许 post-hoc 改）：
  · `VERDICT_PIPELINE_ARTIFACT`：若四类缺陷中任一类在归档原始数值上
    被复现，且修正后**至少一个历史任务的 `c1_guidance.verdict` /
    校准结论 / 符号结论发生方向性改变** → 判定装置确为伪影来源；
    此时**不得**写成「C1 机制成立」，只能写成「历史判定不可直接引用，
    须在修正装置下重跑」，并把受影响的历史 verdict 标
    `superseded_by_re_adjudication`（原文件不删）。
  · `VERDICT_PIPELINE_CLEAN`：若四类缺陷在归档数值上**全部不成立**
    （家族定义与预注册一致、payload/manifest 哈希一致、恢复字段完整、
    finalize 枚举完备），且重判定与历史 verdict **逐条一致** → H12 被否证，
    判定装置不是伪影来源 → 回到 H10 / H11 的机制线继续死磕，
    **不得**把「装置干净」写成「结果达标」。
  · 第五态 `UNINFORMATIVE_ARCHIVE`（诊断型，不是达标、不是机制否证）：
    归档原始数值不足以复算某类缺陷（缺字段 / 缺 seed 级张量 / 缺家族清单）
    → 该类标 `unavailable`，如实记录，不作任何结论。
  · **反向护栏**：H12 无论落在哪一态，都**不**改变
    `minimum(+0.15)` / `expected_strong(+0.25)` / ceiling `0.70`；

    禁止宣称生物接线带来精度优势（`A=0` 为输入信息上界、保度零模型
    8 轮从未输给真实接线）；不静默下调 `expected_strong`、不删失败证据、
    不改写负结果、不编造数值、不换主攻。
