【阶段 A：环境、数据可达性、图构建、天花板、SYNTHETIC 域】
- 环境：先跑 nvidia-smi 与 torch.cuda.is_available()，记录 GPU、显存、CUDA、torch 版本。
- 依赖：干净环境实测缺 scipy / scikit-learn，请自行 pip install scipy scikit-learn pandas opencv-python-headless（不要建 venv）。
- 连接组（Zenodo 10.5281/zenodo.21549559，CC BY 4.0，均已实测可达）:
  edges https://zenodo.org/api/records/21549559/files/connections_biological.csv.gz/content
  annotations https://zenodo.org/api/records/21549559/files/neuron_annotations_flywire_v2.1.0.tsv.gz/content
  eye https://zenodo.org/api/records/21549559/files/right_visual_positions_all_neurons.csv/content
  边表 178MB：用 HTTP Range 只取前 8MB，流式 gzip 解压并忽略截断尾，约 80 万行真实边即可，不要等完整下载。先校验列名。
- 图构建：A[post,pre]=log1p(syn_count)，COO→CSR，sum_duplicates；谱半径归一化 A *= 0.95/lambda（幂迭代 40 步）。禁止行归一化（会把信号稀释到 1e-5）。
- 复眼采样：32x32 帧像素归一化到 [0,1]，cKDTree 找最近复眼坐标 root_id（Voronoi，用 x_axis/y_axis 列，不要用 3D 体素列 x/y）；每图对比度归一化使最亮感受器驱动为 1。
- 读出：cell_type 以 KC 开头的神经元；注释不可用时退化为复眼 BFS 第 2 跳中固定随机 1024 个并标注。特征维 >2000 时先做 PCA(32)，只在训练集拟合（避免 48k^2 矩阵 OOM）。ridge 读出 L2=1e-2，固定 70/30 划分。
- SYNTHETIC 刺激：T=8 帧、32x32、n=400、二分类 direction（半径 3-5 圆点，起始 x 随机 8-24，逐帧 speed=2 向左或向右移动）；另有 flash 任务作对照。天花板 = 8 帧展平成 4096 维做 ridge，报告准确率。
- 阶段 A 条件（每条件 5 seeds=[1,2,3,4,5]，同一批刺激与同一 split）:
  stateless: 每帧独立 3 步 x=tanh(A@x)，8 帧特征取均值。
  lif_homeostasis: v=0.6*v+syn+drive；syn=边级 index_add(上一帧硬脉冲)*8/fan_in*8；硬阈值 0.15，发放后 v-=0.15；软脉冲 sigmoid((v-0.15)*20) 累积后 8 帧取均值。用边级 index_add，不要用 torch.sparse.mm 求梯度（会物化 107101^2 稠密矩阵 OOM）。
  lif_combo: lif_homeostasis + 自适应阈值(thr=0.15+0.05*spike+0.85*(thr-0.15)) + 不应期 2 步 + 真实 E/I 符号(top_nt 为 gaba/glutamate/glycine 的突触前神经元，其出边权重取负)。
  degree_null_lif: 保度重连，保 in/out 度序列、权重与 nnz，保护互反边对。
  A=0: 无图传播，仅输入层读出，退化下界。
- 每条件记录 per-seed 准确率、mean、spike rate、读出特征 std、峰值显存、耗时。阶段 A 结束立刻落盘 result.json 的 stage_A 字段。
