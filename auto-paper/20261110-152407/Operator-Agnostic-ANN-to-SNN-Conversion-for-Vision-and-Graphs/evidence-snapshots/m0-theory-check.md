- 结果 JSON 的**磁盘字节 SHA-256（权威）**：`ea4c05a67300766ed9141bb0f1e99b2407760321f32ab95dcdb6c25e5ec7575f`
- 规范化内存字符串 SHA-256（仅备查）：`65cabcbc2dfa6750739f070fe9f6958c48f3e6436906c98804934aa39260d670` — Windows CRLF 会使二者不同，属编码差异、非内容篡改
- 环境：Python / NumPy 2.4.4｜seed 20261110｜N=64, H=24, C=7, θ=1.0
- 说明：本核验**不训练、不报告分类精度**，只验证固定线性算子类上的代数/概率命题与失效边界。

## P1 精确误差恒等式
`B2hat − B2 = A (E1 W2)` 在 ρ ∈ [0.5, 1.0, 2.0, 5.0, 10.0]、T ∈ [1, 2, 4, 8, 16] 全部 25 格上的最大绝对残差 = **9.881e-15**（浮点精度内）。
这是本次 G3 理论门最硬的证据：恒等式在固定线性算子上**精确**成立，不是近似。

## P2 系统误差按 ρ_n 加权
不加偏置时 `mean(E1) ≈ −1/(2T)`；margin 平移随 ρ 线性放大。加 `β* = θ/(2T)` 后系统项在各 ρ 下同时趋零，且 β* 本身与 ρ 无关。逐格数值见 JSON `P2_rho_weighted_systematic_error`。

## P3 相对误差 ρ-不变（干净隔离版）
同一份 B1/W2/b2 与同一份行和为 1 的 A0，**只**把 A 整体乘 ρ，使 ρ 成为唯一变量（第三轮独立评审指出上一版每个 ρ 重采样 problem，无法干净检验，已修正）。逐 ρ 的 `mean_relative_error` 与 `argmax_agreement` 见 JSON。
**读法约束**：若相对误差仍随 ρ 明显变化，则说明"整体缩放 A"不足以复现成稿 §5.1 的 ρ-不变结论（成稿中 ρ 的变化来自不同聚合算子，margin 结构同时改变）。此项须在 G3 用真实聚合算子重做，**不得把本数值直接当作 ρ-不变性的证明**。

## P4 Hoeffding 型波动上界
δ=0.05，逐节点 × rival class 共 1920 对，**违反数 = 0**；实测/上界比的最大值 = 0.7832。上界 sound 但保守（与成稿 3.2–6.7× 松弛一致）。

## P5 确定性两阶段 vs Bernoulli 第二相
20,000 个激活 × T ∈ [1, 2, 4, 8, 16]：`Σ_t s[t] = n` 命中率 100%，逐样本重建误差 ≤ θ/2，重复运行逐位相同 → **条件方差 0**；对照的 Bernoulli 第二相总数为随机量，方差 > 0。逐 T 数值见 JSON。

## P6 失效边界（关键，支撑"适用条件"而非掩盖）
| 情形 | 是否属于固定线性算子类 | 观测量 |
|---|---|---|
| 固定线性 A | 是 | 恒等式残差 1.776e-15 |
| 每步变化的动态 A_t | 否 | 相对平均 A 的恒等式残差 0.7058（显著非零） |
| max 非线性聚合 | 否 | 脉冲率输出与 ANN 输出最大绝对偏差 1.1669（显著非零） |

即：**原版 ViG 的动态 KNN 图 + max-relative 聚合确实落在本方法适用类之外**，这是可测的失效边界，不是文字声明。新篇必须把它保留为诊断实验（C5），不得删除以美化结果。

## 本核验不能证明什么
- 不证明任何方法在 CIFAR/ImageNet 上精度更高；- 不证明能耗、生物保真或硬件收益；
- 不证明 ρ_n/T 单调判据在真实训练网络上成立（那需要 P4 全量实验）；
- P5 的 Bernoulli 对照是简化的时变概率实现，不是 TPP 官方代码的逐字复现。
