## 3. 必须说明的口径边界（避免夸大）

E1 与 `local_full_v2` **不是同一规模**：v2 全量用 `n_train=5000 / n_val=1000 / n_test=2000 / epochs=1000`，E1 用 `2000/500/500 / epochs=800` 并额外做了 val 工作点选择。因此：

- 不能把 E1 的 1.96/1.84pp 表述为「相对 v2 的 3.10/2.13pp 改进了 X pp」—— 配置不同，不构成配对实验。
- E1 的 teacher 精度也相应更低（MNIST 均值 65.56% vs v2 的 68.29%；CIFAR10 34.12% vs 36.77%）。
- E1 的合法结论是：**在 val 选工作点 + 去 β\* 的协议下，5-seed loss 落在 1.8–2.0pp，且 E4 恒等式精确成立**。若要严格配对，需在同一规模上重跑固定工作点对照（列入 E6）。
