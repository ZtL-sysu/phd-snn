# E18 结果与决策点：三项强结果已闭合，MNIST 精度带需方向

> 数据源：`results/e18/confirmation.json`（10/10 runs，20m21s），脚本 `protocols/run_e18.py`。
> 工作点冻结不变，仅把 `n_train` 2000→3000、`epochs` 800→1000，换未暴露 holdout **seeds 15–19**，`n_test=2000`，统一 fp64 前向。

## 1. 假设被证伪：增大训练规模不改善转换一致性

| 数据集 | E17 (2000/800) | E18 (3000/1000) | 变化 |
|---|---:|---:|---|
| MNIST teacher | 34.02±1.60% | 36.09±2.79% | 略升但方差变大 |
| MNIST loss | 3.79±2.26pp | **7.29±3.82pp** | **变差** |
| CIFAR10 teacher | 27.27±1.67% | 28.18±1.75% | 略升 |
| CIFAR10 loss | 1.57±0.67pp | **2.27±0.76pp** | **变差** |

更长的训练让 teacher 更分离、margin 更大，但低 T 的确定性两阶段量化误差同步放大，SNN 与 ANN 的一致性反而下降。这条改进路径已排除，负结果保留。

**E18 仍 PASS 的项**：能耗 MNIST 9.849/6.251×、CIFAR10 7.347/5.870×（逐 seed 最小 5.938/5.595×）；恒等式残差 5.77e-15 ~ 1.38e-14；teacher 均 >20%。

## 2. 全项目证据总账（E1–E18，四组独立 holdout）

| 冻结目标 | 状态 | 最强证据 |
|---|---|---|
| 横评 T≤4 领先 ≥1.0pp | **PASS** | 5-seed 全量 43.67 / 19.85pp |
| 带内能耗 ≥5×（primary + conservative） | **PASS** | seeds 0–4 / 5–9 / 10–14 / 15–19 共 **20 个独立 seed**，全部 ≥5×；E17 9.103/6.086×、7.603/5.938× |
| 恒等式 <1e-10 | **PASS** | fp64 统一前向 4.88e-15 ~ 1.38e-14 |
| 精度 T≤8 进 1.5pp 带 | **未达** | 四组 holdout 最好：CIFAR10 **1.57pp**（差 0.07，CI 下界 0.983）、MNIST **3.79pp**（差 2.29） |

三个历史陷阱（零脉冲假优势、退化 teacher 假达标、fp32/fp64 混算）已全部识别并修补；所有负结果与实现缺陷保留在证据链。

## 3. 为什么这里需要方向

`contracts/strong-result-no-retreat.md` 禁止自动降级故事、禁止自动下调 1.5pp。`f-research-v1` 修正回路规定：当继续推进需要「新方法族 / 额外算力 / 改变验收口径」时应请求用户方向。当前：

- 参数与工作点已扫过 E1–E18（含 gauge/θ/T 网格、margin 正则、稀疏化、结构性剪枝、低 T、多 seed 稳健选点、增大训练规模）；
- val 上两数据集都有达标点，但 test 5-seed 一致性系统性低于 val，MNIST 尤其明显；
- 再往下要么设计**新的转换机制**（属方法族变更），要么**改变精度带的验收口径**（需用户授权），要么**显著追加算力**。
