# Theoretical Feasibility Audit（G3）

> 生成 2026-11-10｜本审计与 `guidance.md` 的 "Theoretical Feasibility Audit" 摘要一致；此处为完整版。
> 证据等级严格区分：**【本机实跑】**、`【成稿，未公开先验】`、`【文献】`、`【推断，待证】`。

## 1. 因果/算法机制：技术为什么应在本任务上起作用

固定、非负、线性传播算子 A 下，转换误差满足精确恒等式

```
B̂₂ − B₂ = A (E₁ W₂),    E₁ := count₁/T − ReLU(B₁)
```

这不是近似。【本机实跑】M0 在 ρ∈{0.5,1,2,5,10} × T∈{1,2,4,8,16} 共 25 格上最大绝对残差 `9.880984919163893e-15`（浮点精度内）。由此得到两条机制推论：

- **T1（ρ 加权系统项）**：相位随机化下 `E[E₁] = β − 1/(2T)`，闭环偏置 `β*=θ/(2T)` 与 ρ 无关；但把均值误差传播过 A 后，margin 平移为 `ρ_n/(2T)·Σ_h DW_c[h]`，即**系统项按行和 ρ_n 加权**。【本机实跑】P2 逐格数值在 `evidence-snapshots/m0-results.json`；【成稿，未公开先验】`p7-draft.md` §3.4 给出同一推导并实测 `var(U)=0.082 vs 0.083`、`mean(U)=0.481 vs 0.5`。
- **T2（相对误差 ρ-不变）**：margin `Δ_n` 由同一聚合 logits 算出，相对误差由 `‖a_n‖₂‖DW‖₂/(TΔ_n)` 控制而非 ρ_n。【本机实跑】P3 修正版采用**同一份 problem、只把 A0 整体乘 ρ**（第三轮红队指出上一版每 ρ 重采样 problem 不干净），结果 `mean_relative_error` 从 ρ=0.5 的 `0.3056` 到 ρ=10 的 `0.3111`（变化 <2%），`argmax_agreement` 全程 `1.0`。【成稿，未公开先验】§5.1 记录了原预测"sum 聚合 ρ≈169 会灾难退化"被实测推翻、进而给出 ρ-不变解释的过程。

由 T1/T2 得到可先验计算、可证伪的判据 `κ_n = ρ_n / ‖a_n‖₂`：**为 ρ=1 推导的校准律在 κ_n 大且 T≤4 时系统性欠校准，conversion loss 差距随 ρ_n/T 单调增大；ρ≈1 的 CNN 臂上两者非劣效**。这是本新作相对成稿的实质延伸，也是三轮独立红队反复追问的"新推论"落点。

**诚实边界**：第三轮独立红队明确判定 T1/T2/κ_n **不构成「prior-art 无法得到的新数学结果」** —— T1 可由 `A·1 = ρ_n·1` 加 QCFS 零期望偏置一行展开，T2 是尺度抵消的标准观察。本文按 H7 **不声称** T1/T2/κ_n 是 prior-art 无法得到的新数学结果；其价值是可证伪的算子类判据与跨骨干统一协议。`T1 非平凡性` 列为 G3/G4 显式待办（H2），未过不得进 P4/G7 主表。

## 4. 可证伪消融（必须能推翻机制）

| 消融 | 若结果如此则机制被证伪 |
|---|---|
| A1 去 β*（β=0） | 系统项不随 ρ_n 放大，或加 β* 后各 ρ 下系统项不同时趋零 |
| A2 计数解码 vs 膜电位累加 | 两者无差异 → 组件冗余，须删除 |
| A3 Bernoulli 第二相 vs 确定性 s[t] | 确定性化只带来零方差、无可测系统增益 → 组合 delta 不成立 |
| A5 固定图 vs 动态图 | 动态图上恒等式仍成立 → 适用类写错 |
| A6 线性聚合 vs 原版 max-relative | 非线性聚合上恒等式仍成立 → 适用类写错 |
| A7 ρ≈1 的 CNN 臂 vs ρ≠1 的 B2/B3 | CNN 臂上主臂也"显著更好" → 判据不具算子特异性；或 ρ_n/T 无单调关系 → 核心判据被推翻 |
| 全局 | 恒等式浮点残差超容差 → 主卡作废（S1） |

## 5. 会让本项目达不到目标档位的失败模式

1. **T1 平凡化**：G3 证明 T1 可由 `A·1=ρ_n·1` + QCFS 零期望偏置一行照搬，且无新误差界/新校准律/新可覆盖算子类 → 理论贡献坍缩，按 H9 回退 `pivot-with-rescue-route`（纯 benchmark 故事）。
2. **κ_n–T2 张力未解**：T1 预测误差随 ρ 放大、T2 预测相对误差 ρ-不变，二者的适用量纲与比较单元须在 G3 明确（第三轮红队 Q2′），否则主判据自相矛盾。
3. **真实训练网络上单调性不成立**：M0 只证合成算子上的代数/概率命题，**不证明** `ρ_n/T` 单调判据在真实训练网络上成立（H2 明写）。若 P4 趋势检验连续落 failure → S4 回退。
4. **冻结/线性化代价过大**：若 B2 相对原版 ViG 的 ANN teacher 精度损失大到使 conversion loss 无可比意义，须如实报告，不得隐瞒（H6）。
5. **最近邻基线复现失败**：PASCAL 无官方码、TPP 官方码需适配；任一未通按 S2 转 `needs-evidence`，主表不得用文献数值顶替。
6. **组件被判定为已知组合**：三轮独立红队一致指出这是最强拒稿轴。若第 0 批横评显示与 PASCAL/TPP 等价，novelty 回落，按 `[pivot]` 把贡献收敛到统一协议横评 + 失效边界。
