# Startup stage plan

## Goal and tier

Develop a portfolio of ten distinct GNN→SNN candidates with Q2+-capable research plans. Smoke success is a necessary admission screen, not a claim of publication readiness.

## Ordered ownership

| Stage | Owner | Gate |
|---|---|---|
| CCFA startup | `ccf-pipeline-orchestrator` + primary | Scope, immutable resources, outputs, stop rules recorded |
| Idea concretization | `ccf-idea-optimizer` | Mechanism, assumptions, falsifier, contribution type explicit |
| G0 | `ccf-literature-searcher` | 2022–2026 closest-work and baseline clusters with primary URLs |
| Independent red team | `ccf-idea-reviewer` | Closest-work subtraction, fatal risks, readiness vs potential |
| Experiment contract | `ccf-experiment-designer` | Predeclared matched controls, IDs, metric, strong/minimum/failure |
| G1/G2 | Primary | Direct-public real data, saved splits, labels and valid metric |
| G3/G4 | Primary + literature audit | Causal/algorithmic fit and no identified duplicate |
| G5/G6 | Primary | Local resources and feasible strong controls |
| G7 | Actual smoke executor | Frozen gate met in raw outputs; no goalpost movement |
| G8 | Primary | Remaining claim can support a rigorous paper after full validation |
| Validation/handoff | Strict validators + primary | Ordered ledger, structural packet, ten-candidate index |

## Rejections and iteration

A failed candidate is recorded with exact evidence and is not admitted. Repairs involving mechanism or hypothesis create a new candidate version. Reusing the same computation with renamed components or relaxing a threshold is prohibited. Canonical stages are sequential within a candidate; independent literature retrieval may proceed before candidate selection.
