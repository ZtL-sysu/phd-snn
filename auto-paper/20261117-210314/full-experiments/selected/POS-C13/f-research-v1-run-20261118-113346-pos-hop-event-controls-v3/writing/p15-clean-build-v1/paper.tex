\title{Permutation-Equivariant Hybrid Hop-Message Coding for Frozen Graph Positional Representations}

\author{Anonymous}

\begin{document}
\begin{abstract}
Multi-hop positional messages preserve graph structure but are expensive to communicate in frozen graph conversions. We study a narrow representation-coding problem on Chameleon and Squirrel: concatenate raw node features with one-, two- and three-hop normalized messages, quantize each channel using eight Lloyd centroids plus one escape symbol, and account for four-bit symbols, 32-bit escape payloads and per-channel codebooks. Across five split/probe seeds, hybrid reconstruction error is 3.952\% and 4.879\%, while the conservative ledger reduces storage by 7.49$\times$ and 7.60$\times$. Recomputation after node permutation agrees to \texttt{2.22e-16}. A codec-consistent shuffled-hop control, which quantizes globally permuted hop blocks with unchanged ordered-channel codebooks, produces 3.72$\times$ and 3.63$\times$ mean error ratios. Retrained hybrid probes lose 0.083 percentage points on Chameleon and gain 0.768 points on Squirrel relative to raw features. Fixed raw-trained probes favor ordered over shuffled hybrid representations by 9.57 and 9.08 points. The contribution is a conversion-level multi-hop coding and order-control protocol, not a general graph-transformer-to-SNN method.
\end{abstract}

\section{Introduction}


Graph positional information often appears as multi-hop propagation of features or structural identifiers. Concatenating hop-wise messages increases feature width and communication cost, while simple global quantization can distort channel distributions and rare values. Frozen conversion settings make the problem more specific: the graph representation is fixed, and the goal is to serialize a positional message without changing its node-permutation behavior.

Compression error alone is not sufficient evidence. A useful study must also show whether the canonical hop order matters, whether the representation is equivariant to node relabeling, and whether downstream predictions survive without representation-specific retraining. These controls distinguish a structured hop code from a generic high-dimensional quantizer.

This paper evaluates the representation

\[
H = [X, AX, A^2X, A^3X],
\]

where \texttt{A} is a row-normalized graph operator. Each channel is encoded with eight Lloyd centroids and one escape symbol. Escaped values are stored exactly as float32 payloads. The serialization cost is deliberately conservative:

\[
b_{\mathrm{avg}} = 4 + 32 f_{\mathrm{escape}} + \frac{256}{N},
\]

where four bits encode one of eight centroid identifiers or the escape marker, \texttt{f\_escape} is the escaped fraction, and \texttt{256/N} amortizes eight float32 centroids over \texttt{N} nodes.

The central question is whether this hybrid code preserves ordered multi-hop messages at useful storage reduction while remaining node-permutation equivariant and sensitive to hop order. We answer this within two static graphs and explicitly separate three forms of evidence: representation fidelity/storage, retrained linear-probe performance, and fixed raw-probe ordered/shuffled controls.

\section{Related Work}


Positional encodings and graph transformers represent structure through attention mechanisms, learnable structural/positional representations or spectral attention \cite{vaswani2017attention,dwivedi2021graph,kreuzer2021rethinking}. These methods motivate the importance of ordered structural channels, but they do not provide the exact serialization ledger evaluated here.

Graph-model compression studies degree-aware quantization, vector-quantized node representations, aggregation-aware mixed precision and communication compression \cite{tailor2021degreequant,ding2021vqgnn,wang2022qgtc,zhu2023a2q,wan2023adaqp,gholami2022quantization,jacob2018quantization,nagel2021white}. Our method uses standard Lloyd centroids and exact escapes; the contribution is their combined hop-message accounting and order controls, not a new general quantizer.

ANN-to-SNN conversion work addresses output codes, offsets, grouped neurons, early exit and transformer conversion \cite{one-spike,hao2023offset,lv2024group,bu2023optimal,li2023seenn,hu2023fast,zhao2025ttfs,huang2025ecmt,li2024erroraware}. Spiking graph models address spiking graph convolution, dynamic graphs and graph transformers \cite{spikinggcn,spikenet,dy-sign,delay-dsgn,signnn,sun2024spikegraphormer,zhang2025sgnnbench}; compact/geometric graph representations and asynchronous event processing add adjacent context \cite{li2023graph1bit,chaurasia2026sgspose,asgcn}. These systems are adjacent context; the present paper does not train a spiking graph transformer or measure temporal energy.

The differentiation is therefore narrow. The work combines multi-hop positional messages, a conservative codebook/escape format, exact node-permutation recomputation and a non-tautological codebook-order mismatch control for frozen graph representations. It does not claim a new positional encoding, a direct graph-transformer conversion result or broad SNN superiority.

\section{Method}


\subsection{Multi-hop representation}


For node features \texttt{X$\in$R\textasciicircum{}(N$\times$F)} and row-normalized adjacency \texttt{A$\in$R\textasciicircum{}(N$\times$N)}, the ordered representation is

\[
H = [X, AX, A^2X, A^3X] \in \mathbb{R}^{N\times 4F}.
\]

The four blocks retain hop position. The task experiments use labeled nodes only; representation, bit and permutation audits use all graph nodes.

\subsection{Hybrid Lloyd/escape encoding}


For each channel, Lloyd quantization estimates eight centroids. Every value receives one four-bit symbol: one of eight centroid identifiers or an escape marker. Escaped values retain a 32-bit float payload. Each channel stores eight float32 centroids. Here ``event'' means a source-side coded or escaped message symbol; no temporal spike is generated.

For representation rows, codebooks are fitted on all nodes and the largest reconstruction errors are escaped using a threshold and every tied value, avoiding row-order-dependent top-k selection. For task rows, codebooks and escape thresholds are fitted on training nodes only and reused unchanged on validation and test nodes. Escapes are selected at the source encoder; labels and test logits are never used.

The exact average ledger is

\[
b_{\mathrm{avg}} = 4 + 32 f_{\mathrm{escape}} + \frac{256}{N}.
\]

Raw float32 uses 32 bits/value. The eight-centroid Lloyd baseline uses three-bit symbols and \texttt{256/N} codebook overhead. Uniform 8-level coding uses three-bit symbols plus two float32 range endpoints per channel.

\subsection{Permutation and shuffled-hop controls}


For node permutation \texttt{P}, features, adjacency and labels are permuted consistently, \texttt{H} and the hybrid code are recomputed, and the reconstruction is inverse-permuted before comparison. Deterministic sorted Lloyd fitting and threshold-plus-ties escape selection make the audit invariant to row order.

The shuffled-hop control uses one non-identity global permutation \texttt{S} of the four hop blocks. Ordered codebooks are fitted on \texttt{H}; the shuffled raw target \texttt{S H} is quantized with the same codebooks and the same escape-fraction policy. The error ratio is

\[
\rho_S = \frac{\|S H - Q_{\mathrm{ord}}(S H)\|_F/\|S H\|_F}{\|H-Q_{\mathrm{ord}}(H)\|_F/\|H\|_F}.
\]

This compares the same codec family and does not shuffle target and reconstruction together. Five shuffle seeds are aggregated as a graph-level mean; every individual row is retained.

\subsection{Task probes}


Two probe protocols are separated. The retrained protocol fits one linear probe per method, graph and split seed. The fixed protocol fits one raw-feature probe and reuses its weights, normalization, split and test nodes for raw, uniform, Lloyd, hybrid-ordered and hybrid-shuffled representations. Training uses split-train indices, epoch selection uses validation, and final metrics use test indices only. \texttt{results/task-provenance.json} hashes all ten label/split records, the task runner, probe source and exact train/selection/evaluation policy.

\subsection{Representation fidelity and storage}


Hybrid reconstruction error is 3.952\% on Chameleon and 4.879\% on Squirrel. The actual escape fractions are approximately 0.5\%, and the conservative average costs are 4.272 and 4.209 bits/value. Storage reductions are 7.490$\times$ and 7.602$\times$. Both fidelity and storage satisfy the binding gates.

The uniform and Lloyd-only rows show that the hybrid's contribution is not raw compression alone. The exact escapes reduce tail error while the codebook overhead and escape symbols remain visible in the ledger.

\subsection{Permutation and shuffled-hop controls}


Raw and hybrid inverse-permutation errors are \texttt{2.22e-16}, below the \texttt{1e-10} gate. The earlier top-k escape implementation was row-order-sensitive; threshold-plus-all-ties selection removed that defect.

All five shuffle seeds per graph are non-identity. Under the codec-consistent ordered-codebook control, mean error ratios are 3.725$\times$ on Chameleon and 3.626$\times$ on Squirrel, with a minimum of 3.310$\times$. Thus the strong ratio gate passes without comparing different codec families.

For fixed raw probes, ordered hybrid balanced accuracy is 62.99$\pm$2.66\% on Chameleon and 45.49$\pm$0.82\% on Squirrel. Shuffled hybrid means are 53.43$\pm$7.67\% and 36.41$\pm$7.23\%, giving ordered-minus-shuffled gaps of 9.57 and 9.08 pp. These gaps are descriptive order-sensitivity evidence, not proof of causal positional reasoning.

\subsection{Leakage audit and negative evidence}


The first task implementation fitted probes on all labels and produced implausibly high accuracy near 99\%. That run is preserved but excluded. The corrected implementation trains only on split-train indices, selects checkpoints on validation and evaluates once on test. Representation values are unchanged, while task accuracies fall to the accepted range above. No accepted row depends on the leaky run.

\section{Discussion}


The evidence supports three scoped statements. First, the conservative hybrid format preserves the tested multi-hop representation with 3.95--4.88\% error and 7.49--7.60$\times$ storage reduction. Second, node permutation is reproduced to machine precision after deterministic codebook and escape handling. Third, ordered codebooks degrade under non-identity hop-block mismatch, and fixed raw probes prefer ordered over shuffled hybrid features.

The method does not establish that hop order causes a particular graph-transformer computation. Fixed probes show compatibility with the raw ordering, while mismatched-codebook error measures channel-order sensitivity. Retrained probes can compensate for some transformations, and their mixed accuracy differences should not be promoted to general task superiority.

The conservative ledger includes symbol, escape payload and centroid costs, but deployment metadata, packet framing and runtime energy may add overhead. The study uses two heterophilic graphs and five probe seeds. It does not include a complete graph-transformer model, temporal spikes, dynamic graphs, adversarial perturbations or hardware measurements.

The prior-art overlap is substantial because Lloyd quantization, exact escapes and permutation equivariance are established ingredients. The contribution is the combined frozen positional-message format and its paired order controls. A stronger future claim would require real graph-transformer-to-SNN conversion, broader graph families and energy-aware event timing.

\section{Conclusion}


Hybrid hop-event coding preserves ordered multi-hop graph messages at substantially lower conservative storage in the tested frozen setting. All binding representation, storage, permutation and shuffled-hop gates pass. Five-seed retrained task loss is bounded, and fixed raw probes show clear ordered-versus-shuffled gaps. The result is a scoped conversion-level message-coding study, not a general graph-transformer-to-SNN or temporal SNN claim.
