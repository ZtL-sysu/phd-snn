# AGENTS.md：给所有 AI 助手的项目说明

> Codex、Cursor、Claude、Gemini、Grok 等所有 AI 工具在本项目工作前，必须先读完本文件。

## 项目概述
这是一个研究资料库，不是代码项目。内容是"视觉图神经网络免训练转换为脉冲网络"方向的文献、核查记录、通俗讲解和选题判断。读者是项目所有者，他不是这个领域的研究者。实验代码在 ZtL-sysu/gnn2snn。

## 技术栈
全部是 Markdown 文档；图用 Mermaid、SVG 或小型网页。没有需要安装或运行的程序。

## 环境与命令
- 安装依赖：无
- 运行测试：无。提交前改为人工检查：链接能打开、表格能正常显示、没有空字段被悄悄删掉。

## 目录结构
- `docs/literature-tree/`：文献树各版本。`v1` 是 Claude 的草稿，只读。
- `literature/`：按脉络整理的文献条目、定向问题的回答、对草稿的核查、搜索记录。
- `notion/`：Notion 讲解的导出内容、图的源文件、自查结果。
- `tasks/`：任务说明。
- `docs/`：进度、决策、结构说明。

## 内容规范
- 文档使用中文。
- **不编造**：论文、作者、发表处、数字都必须打开过出处页面；找不到写"未找到"或"未核实"。
- **标明核对深度**：读了全文、只读摘要、还是只见过引用。
- **数字带出处**：写明来自哪篇论文的哪张表或哪一节。
- **区分事实、判断、未知**，不要混写。
- **不复制论文原文和图片**：用自己的话概括；图片用链接或嵌入指向原始页面。

## 工作规则（所有 AI 必须遵守）
1. **开始前**：先读 `docs/PROGRESS.md`、`docs/ARCHITECTURE.md`、`docs/DECISIONS.md`，以及自己任务对应的 `tasks/` 文件。
2. **分支与合并**：每个任务新建分支 `<工具名>/<任务简述>`（例如 `codex/literature-01`），做完后推送并创建 PR；不能创建 PR 时只推送分支也可以。**不要自己合并到 `main`，也不用等用户**：Claude 会审查，通过就合并，没通过就在 PR 里留言并在 `docs/PROGRESS.md` 的待办里登记原因。开工前先看有没有自己之前被退回的 PR，先把它改完。新任务依赖还没合并的分支时，从那个分支开新分支，并在 PR 说明里写明依赖。不要强制推送，不要改写已推送的历史。
3. **范围**：只改与当前任务相关的文件。别人的文件发现问题，记到自己的交付物里，不要直接改。
4. **只读文件**：`docs/literature-tree/literature-tree-v1.md` 不要修改，纠错写到 `literature/audit-of-claude-v1.md`。
5. **安全**：不要提交密钥、`.env`、大文件、AI 工具的缓存或对话记录。需要登录或授权（例如 Notion）时停下来让用户本人操作。
6. **验证**：提交前按"环境与命令"里的人工检查过一遍。
7. **结束时**：更新 `docs/PROGRESS.md`（做了什么、没做完什么、遇到的坑）；重要的取舍写进 `docs/DECISIONS.md`。
8. **沟通**：始终用中文回复用户。
