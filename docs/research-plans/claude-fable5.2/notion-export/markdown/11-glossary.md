# 10 术语表

> 本地化来源：[Notion 原页面](https://app.notion.com/p/41b0e3342e6f811e8e69f0040d257997)；由 `export_notion.py` 从只读块数据导出。

> 📌
> **一句话结论**：这一页收录全篇出现的专业词，一词一行，按大致的学习顺序排列。

| 术语 | 解释 | 首次出现 |
| --- | --- | --- |
| 神经网络 | 由大量“神经元”分层连接组成的计算模型，靠训练学出权重 | 第 1 页 |
| 神经元 | 把输入乘权重再相加，再过一个简单函数的计算单元 | 第 1 页 |
| 权重 | 神经元给每个输入乘的系数，训练时学出来 | 第 1 页 |
| 偏置 | 神经元在线性加权和之外额外加上的底数 | 第 2 页 |
| ReLU | 一种激活函数：负数变 0，正数原样输出 | 第 1 页 |
| 训练 / 重训 / 微调 | 用数据和梯度调整权重；重训是从头再训，微调是在已有权重上小幅再训 | 第 0 / 1 页 |
| 预训练模型 / 预训练权重 | 别人已经训练好并公开的模型和权重 | 第 0 页 |
| 边缘设备 | 不在云端机房、直接装在车或相机等终端上的低功耗芯片 | 第 0 页 |
| 图（graph） | 由节点和边组成的结构，不是图片 | 第 1 页 |
| 节点 / 边 | 图里的点和连线；节点带一组数（特征），边表示谁是邻居 | 第 1 页 |
| 特征 | 描述一个节点的一组数 | 第 1 页 |
| 图神经网络（GNN） | 在图上运行的神经网络，每层让节点从邻居收集信息再更新 | 第 1 页 |
| 消息传递 | 节点从邻居那里收集特征的过程 | 第 1 页 |
| 聚合 | 把多个邻居的消息合成一个，常见的有求和、平均、取最大值 | 第 1 页 |
| 取最大值聚合（max 聚合） | 对每个数位分别取邻居中的最大值 | 第 1 页 |
| kNN（k 近邻） | 找距离最近的 k 个点作为邻居 | 第 1 页 |
| 动态建图 / 每层按特征重算 | 每一层都根据当前特征重新用 kNN 挑邻居 | 第 1 页 |
| 固定图 | 邻居事先定好，不随输入变化 | 第 1 页 |
| 扩张 kNN（dilated kNN） | 先找更多近邻，再隔几个取一个，扩大邻居覆盖范围 | 文献库条目 |
| ViG（Vision GNN） | 把图片切块当节点、每层按特征重算 kNN 的视觉图网络 | 第 1 页 |
| MobileViG | 图固定、但仍用取最大值聚合的轻量视觉图网络 | 第 4 页 |
| 点云 | 激光雷达等扫出的一堆三维点 | 第 1 页 |
| DGCNN / EdgeConv | 点云上的动态图网络，EdgeConv 是它每层“重算 kNN + 取最大值”的模块 | 第 1 页 |
| PointNet++ | 点云网络，按三维坐标固定分组、用最大池化 | 第 3 页 |
| 骨架图 / ST-GCN | 关节为节点、骨头为边的固定图；ST-GCN 是在骨架序列上做时空图卷积的模型 | 第 1 页 |
| 事件相机 | 每个像素只在亮度变化时输出一个“事件”的相机，时间分辨率达微秒级 | 第 0 / 4 页 |
| 超像素 | 把颜色相近的相邻像素合成一块，用作图的节点 | 第 3 页 |
| 样条卷积 | 按节点之间的相对空间位置连续调整权重的图卷积运算 | 第 4 页 |
| 体素 | 三维空间切分出来的小方格（三维版的像素） | 第 4 页 |
| 门控（边门控） | 给每条边算一个 0 到 1 的开关系数，决定放多少邻居信息过来 | 第 4 页 |
| 脉冲神经网络（SNN） | 神经元靠发“脉冲”传递信息的网络，模仿大脑 | 第 0 页 |
| ANN | 普通人工神经网络，和 SNN 相对 | 第 1 页 |
| 脉冲 | 脉冲神经元发出的信号，最简单的只有“有 / 没有” | 第 1 页 |
| 膜电位 | 脉冲神经元内部累积的“电压” | 第 1 页 |
| 阈值 | 膜电位超过它就发一个脉冲 | 第 1 页 |
| IF 神经元 | 积分—发放神经元：累积输入，过阈值就发放 | 文献库条目 |
| 减法复位 | 发放后膜电位减去阈值（而不是清零），保留多出来的部分 | 第 1 页 |
| 时间步（T） | 脉冲网络把一次计算拆成的步数；一个数要用 T 步的发放次数表示 | 第 1 页 |
| 发放率 | T 步里发放次数除以 T，用来表示一个数 | 第 1 页 |
| 分级脉冲 | 一个脉冲带一个数值，而不只是“有 / 没有” | 第 1 页 |
| 多阈值神经元 | 有多个阈值、可发出不同大小脉冲的神经元，如 DCGS | 第 2 页 |
| 差分编码 | 每步只发送和上一步相比的变化量 | 文献库条目 |
| 带符号脉冲 | 可以是正也可以是负的脉冲 | 第 7 页 |
| 转换（ANN→SNN） | 把训练好的普通网络换上脉冲神经元、权重照搬 | 第 0 / 1 页 |
| 免训练 | 不再用梯度训练权重，最多用少量数据调阈值 | 第 0 / 1 页 |
| 校准 | 用少量数据调整阈值、偏置等，让转换后结果更接近原网络 | 第 1 页 |
| 替代梯度 / 直接训练 | 绕过脉冲阶梯不可求导的问题，从零直接训练脉冲网络的方法 | 第 3 页 |
| 知识蒸馏 | 让新网络（学生）模仿一个训练好的网络（老师）的输出 | 第 3 页 |
| 卷积网络（CNN） | 用小窗口在整张图片上滑动扫描提取特征的传统看图模型 | 第 2 页 |
| 循环网络（RNN） | 按时间一步步处理序列、记住前文状态的网络 | 第 5 页 |
| 批归一化（BatchNorm） | 把每层输出数值拉回统一均值和范围，让网络更容易稳定工作 | 第 2 页 |
| 最大池化 / 平均池化 | 把一小块区域（或一组邻居）取最大值 / 平均值的操作 | 第 2 页 |
| 侧抑制池化（LIPooling） | 先发脉冲的神经元抑制周围神经元，减少脉冲最大池化的高估误差 | 第 2 页 |
| Transformer / ViT / 注意力 | 让所有输入块按相关程度互相打分交换信息的网络结构，视觉版叫 ViT | 第 2 页 |
| Softmax / LayerNorm / GELU | Transformer 里常见的三种非线性运算：归一化成概率、按层归一化、平滑版 ReLU | 第 2 页 / 文献库 |
| 浮点数（浮点计算） | 普通电脑里带小数点的精确实数（常为 32 位），与整数或二值脉冲相对 | 第 2 页 |
| 增量推理 / 差分推理 | 只处理输入的变化部分，不变的部分沿用上次结果 | 第 5 页 |
| 阈值截断 | 太小的变化直接不传，以节省计算 | 第 5 页 |
| 跳（hop） / 局部子图 | 顺着边走一步叫一跳；图里受波及的那一小片点和线叫局部子图 | 第 5 页 |
| 多跳扩散 | 图上一个节点变化，经过 L 层会波及 L 跳以内的节点 | 第 5 页 |
| token | Transformer 处理的基本单位，图像里通常是一个切分出的图块 | 第 5 页 |
| pJ（皮焦） | 能量单位，1 皮焦等于 10⁻¹² 焦耳 | 第 6 页 |
| 乘加（MAC） / 加法（AC） | 普通网络的基本运算是“乘再加”；只有 0/1 的脉冲只需要“加” | 第 6 页 |
| 突触 | 连接两个神经元、上面带着权重的通道 | 第 6 页 |
| 片上缓存（SRAM） / 片外内存（DRAM） | 芯片内部紧挨计算单元的小容量快内存 / 芯片外的大容量主内存 | 第 6 页 |
| 量化 / 量化网络（QNN） | 用较少位数（如 8 位、4 位整数）表示数值的网络 | 第 1 / 6 页 |
| 训练后量化（PTQ） | 不重训、直接把训练好的网络量化 | 文献库条目 |
| 量化感知训练（QAT） | 训练时就模拟量化，以减少精度损失 | 文献库条目 |
| 类脑芯片 | 专门运行脉冲网络的芯片，如 Loihi 2、SENECA | 第 2 / 6 页 |
| FPGA / ASIC / 流片 | 可现场编程芯片 / 专用定制芯片 / 把专用芯片送工厂实际制造出来 | 第 6 页 |
| 近似最近邻检索 / 召回率 | 在大批向量里快速找最相近 k 个的算法；真正的前 k 名被找对的比例叫召回率 | 第 7 页 |
| 老师模型（教师模型） | 本项目中要被转换的、已训练好的视觉图网络 | 第 3 / 4 页 |
| 许可证 | 代码作者规定别人能如何使用代码的法律条款 | 第 4 页 |
| 失效普查 | 把现有转换方法用到多种视觉图模型上，系统地看哪里会坏、为什么坏 | 第 7 / 8 页 |
| 核对深度 | 文献条目的核实程度：全文、仅摘要、仅见引用 | 第 11 页 |
| ImageNet / COCO / ModelNet40 / NTU RGB+D | 常用数据集：图片分类 / 目标检测 / 点云分类 / 骨架动作识别 | 第 1–4 页 |
| mAP / OA | 目标检测的综合平均精度 / 分类任务的总体准确率 | 第 2 页 / 文献库 |

**三句话小结**

1. 图神经网络的关键词是节点、边、消息传递、聚合、kNN。
1. 脉冲网络的关键词是膜电位、阈值、时间步、发放率、分级脉冲。
1. 能耗部分的关键词是 pJ、乘加与加法、内存读写、量化网络。
